# Unity AR Module — Setup Guide

This guide explains how to set up the Unity 6 AR project for the AR Medical Visualization System.

## Prerequisites
- **Unity 6** (or Unity 2022.3 LTS+) installed via Unity Hub
- **Android Build Support** installed (if deploying to Android)
- **iOS Build Support** installed (if deploying to iOS)
- A 3D model of a human heart (`.fbx` or `.glb`) with separate sub-objects for anatomical regions

## Step 1: Create the Project
1. Open Unity Hub and create a new project.
2. Select the **3D (URP)** template (Universal Render Pipeline is required for the custom shaders).
3. Name it `ARMedicalViz` and create the project.

## Step 2: Install Required Packages
1. Open **Window > Package Manager**.
2. Change the dropdown in the top-left to **Packages: Unity Registry**.
3. Search for and install:
   - **AR Foundation**
   - **Apple ARKit XR Plugin** (for iOS)
   - **Google ARCore XR Plugin** (for Android)

## Step 3: Configure Project Settings
1. Go to **Edit > Project Settings > XR Plug-in Management**.
2. Under the **Android** tab, check **ARCore**.
3. Under the **iOS** tab, check **ARKit**.
4. Go to **Player > Other Settings**:
   - (Android) Set **Minimum API Level** to Android 8.0 (API level 26).
   - (iOS) Set **Requires ARKit** to true and provide an ARKit description.

## Step 4: Import Scripts and Shaders
Copy the folders generated by the system into your Unity project's `Assets` folder:
- `Assets/Scripts/`
- `Assets/Shaders/`
- `Assets/Materials/` (You'll create the materials using the shaders)

## Step 5: Prepare the 3D Heart Model
1. Import your 3D heart `.fbx` into the `Assets/Models/` folder.
2. **CRITICAL:** Ensure the model is split into separate sub-meshes with the following exact names (or edit `RegionHighlighter.cs` to match your naming convention):
   - `heart_left_ventricle`
   - `heart_right_ventricle`
   - `heart_left_atrium`
   - `heart_right_atrium`
   - `heart_mitral_valve`
   - `heart_aortic_valve`
   - `heart_tricuspid_valve`
   - `heart_pulmonary_valve`
   - `heart_septum`
   - `heart_pericardium`
   - `heart_coronary_arteries`
3. Drag the model into the scene, unpack the prefab, and add the `HeartModelController.cs` and `RegionHighlighter.cs` scripts to the Root object.
4. Save it as a new Prefab in `Assets/Prefabs/HeartPrefab.prefab`.

## Step 6: Create the AR Scene
1. Delete the default `Main Camera`.
2. Right-click in the Hierarchy > **XR > AR Session**.
3. Right-click in the Hierarchy > **XR > AR Session Origin** (or XR Origin).
4. Add an **AR Plane Manager** and **AR Raycast Manager** component to the XR Origin.
5. Create an empty GameObject named `AppManager`.
6. Attach the following scripts to `AppManager`:
   - `ARPlacementManager` (Assign the `HeartPrefab` to the `Placed Prefab` slot)
   - `DeepLinkHandler`
   - `UIManager`

## Step 7: Configure Deep Linking (Android)
To allow the React web app to open the Unity app:
1. Go to **Edit > Project Settings > Player > Android > Deep Linking**.
2. Add a URI scheme: `armedviz`

## Step 8: Build and Run
1. Go to **File > Build Settings**.
2. Switch platform to **Android** (or iOS).
3. Click **Build and Run** to deploy to your connected device.
